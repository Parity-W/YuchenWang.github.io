Gait Model 步态模型
小人的动作由该场次的真实遥测数据驱动：步频决定步频周期，步幅决定髋摆幅，触地时间决定支撑相占比，垂直振幅决定重心起伏，速度为地面滚动速度。

Gait Parameters 步态参数
支撑相 = 触地时间 / 步态周期；腾空相为其补集。精英跑者触地常在 200 ms 以内，步幅/身高比 > 1.2 通常意味着较强的蹬伸能力。

Metric Radar 多维雷达
Summary 汇总表
Cadence × Stride 速度分解气泡=速度
速度 = 步频 × 步幅 / 60；灰色虚线为等速线。
Pace–HR 配速心率耦合
同心率下配速越快越好，点越靠左下越优。
Ground Contact × Stride
触地越短、步幅越长＝弹性利用越好。
Correlation 相关性矩阵Pearson r
基于所选场次的全部 split。绿=正相关，红=负相关。
Riegel Exponent 疲劳指数
经典值 b = 1.06。b 越小 → 距离延展能力越强；越大 → 速度衰减越快。
Critical Speed 临界速度
CS≈可持续的最高速度；D′为有限无氧储备（米）。由 D/t = CS + D′/t 线性回归得到。
Model Fit 拟合图
VO₂max 估算Jack Daniels
由各距离 PB 反推，差异反映不同距离的表现一致性。
Pace–HR Decoupling 心率漂移
<5% 耦合良好；>10% 提示耐力 / 散热 / 补水短板。
Raw Splits 原始分段
配速为 min/km；步幅 m、触地 ms、垂直振幅 cm。数据来自 Garmin 原始导出，未平滑。
