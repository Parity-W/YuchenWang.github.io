Metric Radar 多维雷达选中指标

Summary Table 汇总表

Cadence × Stride 速度分解气泡面积 = 速度

速度 = 步频 × 步幅 / 60。等速线以灰色虚线绘出：沿等速线移动意味着同等速度下步频/步幅配比改变。远离等速线向上/向外 = 更快。

Pace–HR Coupling 配速心率耦合

同一心率下配速越快 = 有氧能力越好。点越靠左下越优。

Ground Contact × Stride 触地-步幅

触地时间越短、步幅越长通常代表更好的弹性利用。左下角为「慢而粘地」，右上角为「长步幅但触地久」。

Correlation Matrix 相关性矩阵Pearson r · 全部 split

基于所有场次的所有 split 计算。绿色=强正相关，粉色=强负相关。用于判断「哪个技术变量真正在驱动配速」。

Riegel Exponent 拟合个人疲劳指数

经典 Riegel 取 b = 1.06。b 越小 → 距离延展能力越强（耐力型）；b 越大 → 速度衰减越快（速度型）。

Critical Speed Model 临界速度D = D′ + CS·t

CS = 理论上可长时间维持的最高速度（近似乳酸阈配速）；D′ = 有限的无氧储备（米）。由各 PB 的 (t, D) 线性回归 D/t = CS + D′/t 得到。

Model Fit 拟合图速度 vs 1/时间

Estimated VO₂max 估算Daniels / Jack Daniels 公式

由各距离 PB 反推的 VO₂max 估算值（同一跑步经济性假设下）。差异反映不同距离的表现一致性。

Pace–HR Decoupling 心率漂移后半程 / 前半程

计算方式：后半程 (配速/心率) 相对前半程的变化率。<5% 视为配速与心率耦合良好；>10% 提示耐力或散热/补水上存在短板。

Raw Splits 原始分段

配速列单位为 min/km（秒值已换算）。步幅单位 m、触地 ms、垂直振幅 cm。所有数值来自 Garmin 原始导出，未做平滑。
